# BS5c v0.8.6

Combines the v0.8.5 context-aware library, HA weather/Garmin context, non-waking prompts and post-run yoga routing with the device-local installation captured before deployment.

Preserved changes include HLK screen presence, Master Link role handling, YouTube music/video search and channel-to-podcast menus, playback targets and queue overlays, artwork/navigation refinements, and calibrated HA/MLGW volume routing. Configuration schemas and both regression suites are merged. Runtime credentials, media-library caches and generated backups are excluded from publication; the complete installation rollback remains on the device.

Validation: offline Python and JavaScript regression suites; deployment checks are read-only and do not start media.
